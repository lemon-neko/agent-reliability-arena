# Agent Reliability Arena 参赛包

本目录面向通用 AI 应用创新赛，可直接用于报名、路演、Demo 与答辩。提交前替换以下字段：

```text
赛事名称：{{competition_name}}
参赛赛道：{{track}}
团队名称：{{team_name}}
成员与分工：{{team_members}}
项目链接：{{repository_url}}
演示链接：{{demo_url}}
联系方式：{{contact}}
```

## 使用顺序

1. 从 [报名材料](submission.md) 选择符合字数限制的版本。
2. 使用 [3 分钟/5 分钟路演稿](pitch.md) 排练。
3. 按 [Demo 脚本](demo-script.md) 准备公开交互版和本地完整模式。
4. 使用 [评委问答](judge-qa.md) 做压力演练。
5. 提交前逐项核对 [Evidence Ledger](evidence.md)，不得把规划能力写成已实现。

项目设计事实以 [设计初衷](../product/vision.md) 和 [项目状态](../product/status.md) 为准；比赛材料是叙事层，不是新的事实源。
