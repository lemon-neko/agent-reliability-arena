# 产品路线图

路线图按可独立验收的能力推进，不承诺具体日期。当前完成度以[项目状态](status.md)为准。

| 阶段 | 目标 | 验收证据 | 状态 |
|---|---|---|---|
| v0.2 基线 | HTTP Agent 接入、12/72/180 风险矩阵、门禁、报告与动态 Demo | 协议测试、风险引擎测试、E2E | 已完成 |
| 评测可信度 | 状态级 Oracle、私有用例、重复运行统计和基线 Diff | 固定 Seed 回归、状态快照测试 | 下一步 |
| 规模化执行 | Run 级任务扇出、持久取消、队列隔离与资源配额 | 180 Run 压测与 Worker 恢复测试 | 规划中 |
| 企业交付 | 服务端 PDF、报告签名、团队策略、CI 门禁和历史趋势 | 脱敏与权限测试、版本对比报告 | 规划中 |
| 公开复验 | 官方 Runner、证明链、可复现 Endpoint 与审核工作流 | Registry CI、复测日志和公开榜单 | 规划中 |
| 扩展形态 | 浏览器/桌面 Agent 与可审核的厂商协议适配 | 独立隔离层和新风险包 | 远期 |

近期优先级是“评分更可信”而不是盲目增加测试数量：先补状态与副作用差分，再扩充私有风险包和统计解释，最后做大规模执行与商业化控制面。
